# Pricebooklevel200 — Business Rules & Validation

> Every rule gets a stable ID (e.g. <MOD>-RULE-001) so Stage 4's test docs can trace back to it.

Source: `docs_from_blueprint/module/Pricebooklevel200/03-business-rules-and-validation.md`, itself condensed
from `blueprint/module/Pricebooklevel200/02-validation-rules.md` ("Pass 2"), re-verified in `07-risk-findings.md`
("Pass 7") and `08-consolidation-review.md` ("Pass 8"). Rule IDs below are remapped from the source's own
`PBL200-VAL-###` numbering to `PBL200-RULE-###` (same sequence, 1:1). Original file:line legacy citations are
in `blueprint/module/Pricebooklevel200/02-validation-rules.md` if a rule ever needs re-verification against the

**Confidence column**: every rule below is *Confirmed* — each was extracted from a direct, full read of the
module's own code (Pass 2) and independently re-verified by re-reading the cited source file/line ranges (Pass
7/8). None is an inferred/deduced rule.

## Additional confirmed-dead/wrong-table findings (not independently numbered in the source)

The source blueprint separately confirms, without assigning a new rule ID, three further files that are
verbatim leftovers from an unrelated module (Campaigns): one renders a full unrelated related-list page with
zero business logic of this module's own; two others insert/delete rows in that unrelated module's own
relationship tables. Where any of these three files' own SQL exists, it is correctly parameterized — they are
not independently injectable, but are confirmed misfiled/dead features, carried forward in
`risks-and-open-questions.md` and `integrations.md` (`docs_from_blueprint/module/Pricebooklevel200/03-business-rules-and-validation.md`
§3.15; `blueprint/module/Pricebooklevel200/02-validation-rules.md` §"Additional confirmed-dead/wrong-table
findings").

  re-verification against the original source.

- **16 of the 42 rules document a confirmed, unmitigated SQL injection** (rules 3, 8, 10, 17, 20, 29, 30, 31,

  injection in every module blueprinted in this documentation series to date.
