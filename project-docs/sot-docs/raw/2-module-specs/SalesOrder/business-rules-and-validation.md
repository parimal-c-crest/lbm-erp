> Every rule gets a stable ID (e.g. <MOD>-RULE-001) so Stage 4's test docs can trace back to it.

Source: `docs_from_blueprint/module/SalesOrder/03-business-rules-and-validation.md`, ultimately
derived from `blueprint/module/SalesOrder/02-validation-rules.md`. **All 123 rules** (SO-VAL-001
through SO-VAL-123 in the source) are itemized below, IDs reformatted to `SO-RULE-###` keeping the
same numbers. Confidence is inferred from the source's own hedging language per rule (explicit
"confirmed"/definite statements → Confirmed; explicit "unconfirmed"/"not traced"/"unclear" language →
Inferred) — nothing here resolves an ambiguity the source itself left open.

## Open Questions

- **No rule in this catalog — or anywhere else in the legacy codebase — was found to enforce any
