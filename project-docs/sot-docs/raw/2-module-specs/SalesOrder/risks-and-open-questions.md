# SalesOrder — Risks & Open Questions

Source: `docs_from_blueprint/module/SalesOrder/09-risks-and-open-questions.md`, itemized in full
against its underlying sources `blueprint/module/SalesOrder/07-risk-findings.md` (risk
re-verification) and `blueprint/module/SalesOrder/08-consolidation-review.md` (final consolidated
risk register and master open-questions list, §4–§5) — the docs_from_blueprint file itself only
gives representative items grouped by theme; every individual item below is pulled from the deeper
`blueprint/` consolidation pass to satisfy full itemization. This is the pilot module; nothing here
is compressed or dropped for brevity.

**Source count note, preserved as-found, not resolved**: `08-consolidation-review.md` states "47
distinct open questions" / "47 numbered items" in its own header and closing summary, but its actual
enumerated list (§4, themes A–I) runs to **59** individually numbered items (22+2+10+6+2+6+5+4+2).
The document's own footnote claims this reflects "63 raw entries → 47 consolidated... 16 duplicates
merged," but the visible numbered list itself is not compressed to 47 anywhere in the source text.
Rather than silently pick one number, all 59 individually enumerated items are itemized below
(SO-OQ-001 through SO-OQ-059) — itemizing the fuller list is the safer failure mode for a module
spec whose stated discipline is "never let ambiguity get silently resolved," and dropping 12 items
to hit a stated count would be actively worse. The source's own count discrepancy is carried forward
as its own open item, not resolved here.
